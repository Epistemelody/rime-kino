# proj-arc

Historical, **non-runtime** snapshots. kino does not deploy this tree.

`cloverplus/` is a **local customized archive**, not a full checkout of any single upstream. It was assembled from:

- [fkxxyz/rime-cloverpinyin](https://github.com/fkxxyz/rime-cloverpinyin) (四叶草拼音) — pinyin habits, paired punctuation, Nord Weasel skin
- [shenlebantongying/rime_latex](https://github.com/shenlebantongying/rime_latex) — LaTeX math-symbol schema and dictionary (`latex.schema.yaml`, `latex.dict.yaml`)

plus local edits. Treat paths here as evidence for overlay punctuation and symbol history, not as vendored products.
